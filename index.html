FAQ

Common questions answered

Is this detected by anti-cheat?

GamerDoc uses hardware-level input processing and screen color analysis — no memory reading, no injection, no drivers. The software runs externally and is designed to minimize detection vectors.

What do I need to use it?

Windows 10/11, any modern GPU (AMD, Intel, NVIDIA), and a Makcu hardware device for the mouse input layer. Setup takes under 5 minutes.

Can I use it on multiple PCs?

Each license is bound to one hardware ID (HWID). Need to change computers? Contact support for a HWID reset.

How do I get my license key?

After purchase, your key is delivered instantly via email and Discord DM. Keys activate immediately — no waiting.

Refund policy?
