Questions

The ones people actually ask before buying.

What is KamilColorbot?

A pixel-based color detection tool built specifically for Valorant. It reads enemy outlines from your display and helps smooth your aim through a custom profile system.

Which games are supported?

Valorant only. Every setting, every tuning curve, every update is built around how Valorant renders enemies on screen.

What do I need to run it?

A Windows PC and a Makcu USB device. The Makcu handles mouse input so the aim movement stays off the kernel — that's the piece that keeps it undetected. Full specs are in the Discord setup guide.

Can I use it on more than one PC?

Both plans cover one PC activation. Reach out on Discord if you need something else — we'll sort it out.
