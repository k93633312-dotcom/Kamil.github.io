Questions

The ones people actually ask before buying.

What is AERV?

A small studio building slotted cheats for competitive FPS. Four products total — Colorbot and Woofer live, two ESPs in deployment. Every tool runs on a hard slot cap with direct developer support.

Which games are supported?

Colorbot and ESP target Valorant. The upcoming FaceIt ESP targets CS2 on FaceIt. Manual Woofer is game-agnostic — it works wherever an HWID ban blocks you.

What do I need to run the Colorbot?

A Windows PC and a Makcu USB device. The Makcu handles mouse input so the aim movement stays off the kernel — that's the piece that keeps it undetected. Full specs are in the Discord setup guide.

Can I use it on more than one PC?

Every plan covers one PC activation. Lifetime includes HWID transfer. Reach out on Discord if you need something else — we'll sort it out.

How do I buy?

Join the Discord, open a ticket, and we'll walk you through access and payment. PayPal, BTC, LTC, ETH, USDT accepted. Takes a few minutes.

Is Manual Woofer included with the Colorbot plan?

Yes. Any Colorbot slot comes with Woofer access at no extra cost. You can also grab Woofer standalone — ask in Discord for pricing.

What's the refund policy?

No refunds once access is delivered. If something isn't working, contact support first — we'll fix it before calling it done.
